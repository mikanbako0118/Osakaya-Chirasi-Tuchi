# 大阪屋ショップ チラシ特売通知ボット

毎朝7時に「大阪屋ショップ 上北島店」のチラシを自動で読んで、
**その日に買える本当に安い商品だけ**を Discord に投稿します。

- **月額0円**（GitHub と Google の無料枠だけで動きます）
- **Mac の電源を入れておく必要なし**（GitHub のサーバーが勝手に動きます）
- **クレジットカード登録も不要**

---

## 1. そもそも GitHub Actions とは

ものすごくざっくり言うと **「GitHub が無料で貸してくれる、時間になったら勝手に動くパソコン」** です。

```
毎朝 JST 7:00
   ↓
GitHub のサーバーが起動
   ↓
① トクバイのサイトからチラシ画像を2枚ダウンロード
   ↓
② 画像を4分割して(文字を大きく読むため)Gemini に見せる
   ↓
③ Gemini が「今日買える安い商品」だけを抜き出して文章にする
   ↓
④ その文章を Discord に投稿
   ↓
サーバーは片付けられて終了(次の朝また起きる)
```

あなたがやることは、**このコードを GitHub に置いて、鍵(APIキー)を2つ登録するだけ**です。
プログラミングの知識は要りません。全部ブラウザだけで完結します。

## 3. 事前に用意するもの

| 必要なもの | 入手先 | 備考 |
|---|---|---|
| GitHub アカウント | https://github.com/signup | 無料 |
| Gemini の APIキー | https://aistudio.google.com/apikey | **無料。カード登録不要**（Googleアカウントでログイン → 「Create API key」） |
| Discord の Webhook URL | 投稿したいチャンネルの設定 → 連携サービス → ウェブフック | 既にお持ちのものを使えます |

> ⚠️ **APIキーと Webhook URL は絶対にコードに直接書かないでください。**
> あとで説明する「Secrets」という金庫に入れます。

## 4. セットアップ手順

### 手順 1: リポジトリ（コードの置き場所）を作る

1. GitHub にログインして、右上の **`+`** → **New repository** をクリック
2. **Repository name** に `osakaya-flyer-bot` と入力
3. **Private** を選ぶ（← 重要。公開すると設定が他人に見えます）
4. **Create repository** をクリック

### 手順 2: ファイルを4つ置く

ブラウザだけでできます。**ファイル名にスラッシュ `/` を入れるとフォルダが自動で作られます。**

作成したリポジトリのページで、以下を4回繰り返してください。

1. **Add file** → **Create new file** をクリック
2. 上の「Name your file...」欄に下表の**ファイル名**を入力
3. 下の広い枠に、その**ファイルの中身**を全部コピペ
4. 一番下の **Commit changes** → **Commit changes** をクリック

| 回 | 入力するファイル名 | 貼る内容 |
|---|---|---|
| 1回目 | `requirements.txt` | requirements.txt の中身 |
| 2回目 | `scripts/osakaya_flyer.py` | osakaya_flyer.py の中身 |
| 3回目 | `.github/workflows/osakaya-flyer.yml` | osakaya-flyer.yml の中身 |
| 4回目 | `README.md` | このファイルの中身（任意） |

### 手順 3: 鍵を金庫に入れる（Secrets 登録）

1. リポジトリの上部メニュー **Settings** をクリック
2. 左サイドバーの **Secrets and variables** → **Actions** をクリック
3. 緑の **New repository secret** をクリック
4. 次の2つを、**1つずつ**登録します

**1つめ**
- Name: `GEMINI_API_KEY`
- Secret: Google AI Studio で取得したキー（`AIza...` で始まります）を貼る
- **Add secret** をクリック

**2つめ**（もう一度 New repository secret から）
- Name: `DISCORD_WEBHOOK_URL`
- Secret: `https://discord.com/api/webhooks/...` を貼る
- **Add secret** をクリック

> 名前は**1文字でも違うと動きません**。大文字とアンダースコアに注意してください。
> 登録後は中身を見ることはできません（GitHub の仕様）。忘れた場合は上書き登録します。

### 手順 4: 手動で1回テストする

朝7時を待たずに、その場で動作確認できます。

1. リポジトリ上部の **Actions** タブをクリック
2. 確認画面が出たら **I understand my workflows, go ahead and enable them** で有効化する
3. 左のリストから **大阪屋ショップ チラシ特売通知** をクリック
4. 右側の **Run workflow** → 緑の **Run workflow** をクリック
5. 30秒ほどで一覧に実行が現れます。クリックすると進行状況が見られます
   - 緑のチェック ✅ … 成功。Discord を確認してください
   - 赤いバツ ❌ … 失敗。クリックしてログを開くと原因が書かれています

ログには実際に取得した画像URL・使用されたモデル名・生成された文章がそのまま出るので、
うまくいかない時はここを見れば何が起きたか分かります。

これで完了です。あとは毎朝自動で届きます。

## 5. 時刻を変えたい

`.github/workflows/osakaya-flyer.yml` の `cron:` の行を書き換えます。
**GitHub は UTC（世界標準時）で動くので、日本時間から9時間引いた値**を書きます。

| 日本時間で動かしたい時刻 | 書く値 |
|---|---|
| 朝 6:00 | `cron: "0 21 * * *"` |
| 朝 7:00（初期設定） | `cron: "0 22 * * *"` |
| 朝 8:00 | `cron: "0 23 * * *"` |
| 朝 9:00 | `cron: "0 0 * * *"` |
| 夕方 17:00 | `cron: "0 8 * * *"` |

書き方は `"分 時 日 月 曜日"` で、`*` は「毎」の意味です。

> ⚠️ GitHub 側の混雑で、指定時刻から**数分〜数十分遅れることがあります**（GitHubの仕様で、回避できません）。
> 「7時ぴったり」が必要な用途には向きません。

## 6. 費用について

**結論: 0円で運用できます。**

| 項目 | 無料枠 | このボットの使用量 |
|---|---|---|
| GitHub Actions | Private リポジトリでも月2,000分 | 1回1〜2分 × 30日 = 月60分程度 |
| Gemini API | 1日あたり250〜1,500リクエスト（モデルによる） | **1日1リクエスト** |

どちらも無料枠に対して桁違いに小さいので、超える心配はほぼありません。

### 知っておいたほうがいいこと

- **無料枠の条件は変わることがあります。** 現時点の内容は https://ai.google.dev/gemini-api/docs/rate-limits で確認できます。
- **無料枠では、送ったデータが Google のサービス改善に使われる場合があります。**
  今回送るのはスーパーのチラシ画像だけなので実害はないと考えますが、事実としてお伝えします。
  気になる場合は有料ティア（従量課金）に切り替えると対象外になります。
- 1日1回を大きく超える頻度で回すと無料枠に当たります。その場合は自動で待って再試行しますが、
  それでもダメなら Discord にエラー通知が届きます。

## 7. うまく動かない時

### ずっと動いていたのに、突然止まった
**60日間リポジトリに何も変更がないと、GitHub は自動で定期実行を止めます**（よくある落とし穴）。
Actions タブから手動で1回実行するか、README を少し書き換えて Commit すれば復活します。

### ⚠️ で始まるエラーメッセージが Discord に届いた
このボットは**失敗しても黙って終わらず、Discord にエラーを投げる**ようにしてあります。
よくある原因:

| メッセージに含まれる語 | 原因と対処 |
|---|---|
| `チラシ画像のURLが1件も見つかりません` | トクバイ側のページ構造が変わった。`IMAGE_ID_RE` の正規表現を直す必要あり |
| `すべてのモデルで失敗しました` | ログに各モデルの理由が出ます。下の「モデル名」の項へ |
| `API key not valid` / `401` / `403` | APIキーが間違っている。Secrets を再登録 |
| `429` / `RESOURCE_EXHAUSTED` | 無料枠の上限。自動で待って再試行しますが、頻繁なら実行間隔を空ける |
| `404` (Discord関連) | Webhook が削除されている。作り直して Secrets を更新 |

### モデル名で失敗する場合
Google はモデル名を時々変更します。そのため `MODEL_CANDIDATES` に候補を4つ並べて、
上から順に試すようにしてあります。全部ダメだった場合は
https://aistudio.google.com/ で現在使えるモデル名を確認し、
`scripts/osakaya_flyer.py` の `MODEL_CANDIDATES` の先頭に追加してください。

### 何も届かない（成功もエラーも）
Secrets の**名前のスペルミス**が最有力です。`GEMINI_API_KEY` と `DISCORD_WEBHOOK_URL` を確認してください。

### 内容がおかしい（期限切れの商品が載る等）
`scripts/osakaya_flyer.py` の `PROMPT_HEADER` が AI への指示文です。
ここは普通の日本語なので、気になる点を書き足せば挙動が変わります。
たとえば「お菓子は載せない」「1000円超の商品は除外」など自由に追記できます。

読み取り精度が物足りない場合は、`TILE_COLS` と `TILE_ROWS` を `3` に上げると
より細かく分割して読ませられます（画像枚数が増えますが、無料枠には十分収まります）。

## 8. その他

- **店を変えたい場合**: `SHOP_ID` を変えるだけです。トクバイでその店のページを開くと、
  URL の中に `/170244/` のような数字があります。それが店舗IDです。
- **チラシが1枚だけの週**もあります。その場合は自動的に1枚だけ処理します。
- **チラシが出ていない期間**（更新の谷間）は、リダイレクト先が古いチラシになることがあります。
  その場合 AI が「今日に該当する商品なし」と判断して、その旨を投稿します。
- **サイト側の作りが変わると壊れます**。これは Web から情報を取る仕組み全般の性質です。
  壊れたらエラー通知が来るので気づけます。
- **利用規約**: 個人が自分用に1日1回読む範囲を想定しています。
  取得頻度を大きく上げたり再配布したりする場合は、トクバイの利用規約を確認してください。
